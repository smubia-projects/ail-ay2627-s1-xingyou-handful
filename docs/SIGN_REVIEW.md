# Handful sign review

Thank you for reviewing Handful's signs. Handful is a Duolingo-style app for learning ASL. Most signs now also show a **handshape drawing** (from public-domain and CC-licensed ASL alphabet and number drawings) and a **movement arrow** on the body diagram. Each sign is described in writing: the **handshape**, the **location** on the body, the **movement**, and a short **memory tip** for learners.

These descriptions were drafted by someone who does not sign, so **please correct anything that is wrong, unclear or unnatural**. The app won't be released until these descriptions have been approved.

## How to review

For each sign:

1. Read the description and check it against how the sign is really made.
2. Tick **Approved** if it is correct as written. Otherwise tick **Needs changes** and write the correction in **Notes**.
3. Also check the **memory tip**. It should be accurate, respectful and not misleading about the sign's origin.

The app shows location as one dot on a simple body outline, and only knows 5 locations: **forehead, mouth, chin, chest**, or **in front of the body**. If none of these fits, please say so in the notes.

If a sign has common regional or variant forms, note which one you'd recommend teaching first.

Each sign also has a **dictionary pre-check** note. The descriptions were compared against the [Lifeprint ASL dictionary](https://www.lifeprint.com/) and other dictionary sources, and some wording was corrected. This is only a first pass. It does not replace your review.

Some signs also have a **Face** line (facial expression or head movement). Please check these carefully: the wording is a beginner's summary of ASL non-manual markers and may be too simple or wrong.

The app has a **left-handed mode** that mirrors the drawings and arrows. If any sign should *not* simply be mirrored for left-handed signers (for example the letters J and Z), please say so.
