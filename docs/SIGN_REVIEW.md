# SignPath sign review

Thank you for reviewing SignPath's signs. SignPath is a Duolingo-style app for learning ASL. Each sign in the app is described in writing: the **handshape**, the **location** on the body, the **movement**, and a short **memory tip** for learners.

These descriptions were drafted by someone who does not sign, so **please correct anything that is wrong, unclear or unnatural**. The app won't be released until these descriptions have been approved.

## How to review

For each sign:

1. Read the description and check it against how the sign is really made.
2. Tick **Approved** if it is correct as written. Otherwise tick **Needs changes** and write the correction in **Notes**.
3. Also check the **memory tip**. It should be accurate, respectful and not misleading about the sign's origin.

The app shows location as one dot on a simple body outline, and only knows 5 locations: **forehead, mouth, chin, chest**, or **space** (in front of the body). If none of these fits, please say so in the notes.

If a sign has common regional or variant forms, note which one you'd recommend teaching first.
